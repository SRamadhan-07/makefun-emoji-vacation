A tiny Python program that writes exactly one emoji to /output/entry.txt: 🌅, a sunrise over the ocean standing in for a dream vacation — one quiet morning by the sea, told in a single character. That is 1 character, inside the 1-to-8-character gate. The output is byte-identical on every run, with no trailing newline.

## Run it

```sh
python3 main.py
```
